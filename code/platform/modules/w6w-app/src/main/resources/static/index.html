QUICK GUIDE

Using your workflow workspace

Follow a request from start to finish, or create a workflow package for review.

Start a request

  1. Choose Start a workflow and select a process.
  2. Fill in the fields marked *. Cancel safely closes the form without creating a case.
  3. After starting, use My work to open the next task.

Work on a task

  1. Choose your local demo identity at the top of the page.
  2. Open a task, review its case information, and complete the form.
  3. Use an outcome such as approve or reject when shown. Save for later leaves the task open; Complete task moves the workflow forward.

Track a case

  1. Open Cases and search by case ID or workflow.
  2. Open Details to see the current step, completed activities, and final resolution.

Create and maintain a workflow

  1. From the repository root, run .\w6w.ps1 new --key my-request --template approval --owner my-team --domain requests.
  2. Edit the generated CWM, form, and data schema files under code/workflows/domains/.
  3. Run .\w6w.ps1 validate <workflow.cwm.yaml>, test <workflow.cwm.yaml>, and diff <workflow.cwm.yaml>. After review, use deploy-local my-request to reload it in this workspace.
